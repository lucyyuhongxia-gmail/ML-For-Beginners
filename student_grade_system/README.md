# 学生成绩管理系统（控制台版示例框架）

此目录提供基于需求与设计文档的可运行框架，展示如何使用 Python 基础语法、文件读写与简单排序算法管理学生成绩。所有数据存放在 `data/` 目录的 JSON/CSV 文件中，便于课堂演示。

## 结构
- `cli.py`：命令行入口，菜单驱动的交互。
- `file_store.py`：文件路径、读写封装、日志与备份。
- `models.py`：基础校验与辅助函数（唯一性、自增考试 ID、成绩校验）。
- `student_service.py` / `exam_service.py`：学生、考试的增删改查。
- `score_service.py`：成绩录入、批量导入、统计。
- `ranking.py`：使用选择排序与插入排序生成排名。
- `reporting.py`：控制台表格与 PDF/Text 导出。
- `data/`：示例数据文件；`logs/`：导入失败或异常的日志；`reports/`：报表输出。

## 运行
```bash
python -m student_grade_system.cli
```
启动后按菜单提示输入数字选择功能。示例数据已预置两名学生与两场考试，便于直接体验排名、统计与报表导出。

## 说明
- 排序实现仅使用基础选择/插入算法，便于教学讲解。
- 若系统未安装 `fpdf`，报表自动降级为文本文件输出（同路径同名）。
- 备份功能将 `data/` 文件复制到 `backup/时间戳` 目录，可手动恢复覆盖。
