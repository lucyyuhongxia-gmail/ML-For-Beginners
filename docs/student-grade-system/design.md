# 学生成绩管理系统设计文档（控制台版）

## 总体设计
- **运行方式**：命令行交互，菜单驱动。所有数据通过文件读写实现持久化，适合在课堂示范基础算法与文件处理。
- **数据格式**：
  - `students.json`：存储学生基础信息列表，每条记录包含学号、姓名、班级、联系方式。
  - `exams.json`：存储考试元信息（考试 ID、名称、日期、备注）。
  - `scores.csv`：二维表格式存储成绩（exam_id, student_id, score），便于导入导出。
  - 可选 `backup/` 目录存放定期备份副本。
- **算法约束**：排序与搜索均使用基础算法（冒泡、插入、选择、线性查找），禁止调用高阶库排序，便于教学展示。
- **依赖**：核心逻辑基于标准库；PDF 生成功能优先使用 `fpdf`（若未安装则降级生成文本文件并提示）。

## 模块划分
| 模块 | 职责 | 关键数据结构 / 算法 |
| --- | --- | --- |
| `file_store` | 负责文件路径管理、读写封装、备份恢复。 | 使用 `open` 进行读写；备份采用文件复制。 |
| `models` | 定义学生、考试、成绩的 Python 字典结构及基本校验函数。 | 列表/字典表示记录；线性校验避免重复学号或考试 ID。 |
| `student_service` | 学生增删改查、模糊搜索。 | 线性查找；按姓名/班级过滤。 |
| `exam_service` | 考试创建、修改、删除与查询。 | 线性查找；日期字符串校验。 |
| `score_service` | 添加/更新成绩、批量导入导出、统计。 | 冒泡/选择/插入排序；均值计算；缺考统计。 |
| `ranking` | 单次考试排名、平均分排名生成。 | 基础排序（冒泡/选择）；按分数降序，处理并列。 |
| `reporting` | 控制台表格输出、PDF/文本导出。 | 对二维数组进行列宽计算；PDF 调用 `fpdf`。 |
| `cli` | 菜单驱动入口，协调各服务。 | 输入校验；异常捕获与友好提示。 |

## 核心流程
1. **启动**：`cli` 加载 `students.json`、`exams.json`、`scores.csv`；若文件缺失则创建空文件。
2. **学生管理**：
   - 新增学生：校验学号唯一后写入 `students.json`。
   - 修改/删除：线性查找定位记录，更新后整体写回文件。
3. **考试管理**：
   - 创建考试：生成自增考试 ID，存入 `exams.json`。
   - 删除考试：提示同时删除相关成绩行。
4. **成绩录入/修改**：
   - 录入时校验学生与考试存在；成绩存入 `scores.csv`（若已有则覆盖）。
   - 支持读取外部 CSV 文件批量导入，异常行记录至日志或提示。
5. **排序与统计**：
   - 单场成绩排名：从 `scores.csv` 过滤对应考试，使用选择排序按分数降序排列。
   - 平均分排名：聚合同一学生多场成绩，计算平均后用插入排序输出。
   - 统计数据：遍历计算最高/最低/平均分与缺考人数。
6. **报告输出**：
   - 控制台：使用固定宽度格式化二维数组展示表格。
   - PDF：调用 `fpdf` 生成标题、表头、表格；若依赖缺失则输出 `.txt` 并提示安装。
7. **备份与恢复**：
   - 通过 `file_store` 将当前数据文件复制到 `backup/` 带时间戳目录。
   - 恢复时选择指定备份覆盖当前文件。

## 交互设计（菜单草案）
1. 学生管理
   - 1.1 新增学生
   - 1.2 查看/搜索学生
   - 1.3 修改学生信息
   - 1.4 删除学生
2. 考试管理
   - 2.1 创建考试
   - 2.2 查看/修改考试
   - 2.3 删除考试
3. 成绩管理
   - 3.1 录入/修改成绩
   - 3.2 导入成绩文件
   - 3.3 导出成绩文件
4. 排名与统计
   - 4.1 单次考试排名
   - 4.2 多次平均分排名
   - 4.3 成绩统计（最高/最低/平均/缺考）
5. 报表与备份
   - 5.1 生成 PDF/文本报表
   - 5.2 数据备份
   - 5.3 数据恢复
6. 系统设置
   - 6.1 切换数据目录
   - 6.2 退出并保存

## 错误处理与校验
- 输入校验：分数必须为 0-100（或自定义上限）；日期格式校验；学号、考试 ID 不为空。
- 文件操作：写入前生成临时文件，完成后替换原文件；失败时回滚并提示。
- 异常日志：将批量导入失败行、文件读写异常记录到 `logs/system.log`。

## 测试要点
- 学生/考试增删改查的文件持久化正确性。
- 单次排名与平均分排名排序结果与并列规则正确。
- PDF 缺失依赖时的降级提示与文本输出。
- 备份与恢复流程：在备份后删除数据再恢复，结果应一致。
- 跨平台路径与编码（UTF-8）兼容性。
