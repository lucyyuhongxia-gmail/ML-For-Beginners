# 学生成绩管理系统需求文档（控制台版）

## 背景与目标
教师需要一个基于文件存储的简易成绩管理工具，能够在无数据库、无框架的环境下运行，并演示 Python 基础语法（列表、搜索/排序、二维数组、文件读写等）的应用。系统需保证数据持久化，便于课堂演示与日常使用。

## 关键需求
- **用户角色**：单一角色（学科教师），无需登录与权限控制。
- **学生管理**：
  - 新增学生（学号、姓名、班级、联系方式可选）。
  - 按学号、姓名查询或模糊搜索。
  - 修改学生信息（不得修改学号唯一性约束）。
  - 删除学生（需提示存在成绩记录时的确认）。
- **考试与成绩管理**：
  - 记录多场考试（考试名称、日期、科目/章节备注）。
  - 为学生添加或修改单场考试成绩。
  - 支持批量导入/导出成绩的文本文件（如 CSV）。
- **排序与统计**：
  - 按单次考试成绩排名（使用选择/插入/冒泡等基础排序实现）。
  - 按多次考试平均分排名（可选择权重或默认等权重）。
  - 统计单次考试的最高/最低/平均分，统计缺考人数。
- **输出与打印**：
  - 支持在控制台查看学生列表、成绩表、排名表。
  - 可将指定考试的成绩单、平均分排名、或单个学生的成绩汇总导出为 PDF 文件，方便打印。
- **数据存储**：
  - 所有数据存储在磁盘文件，推荐使用 CSV/JSON 文本格式，禁止依赖数据库。
  - 读写均使用 Python 文件操作（`open/read/write`），不依赖高级 ORM。
  - 应提供数据备份与恢复入口（复制文件或导出归档）。
- **可用性要求**：
  - 控制台菜单导航清晰，输入有基本校验（避免空值、负分数）。
  - 提示语与错误信息友好，支持中文界面。
  - 代码示例保持易读，便于教学。

## 非功能性需求
- **环境约束**：仅使用 Python 标准库与基础语法；PDF 生成可选用轻量库（如 `fpdf`），若缺失则提供文本导出替代方案。
- **性能**：面向班级/年级规模（数百条记录），基础排序算法即可满足需求。
- **可移植性**：在 Windows/macOS/Linux 的命令行环境均可运行；文件路径应避免硬编码。
- **可靠性**：关键操作需确认提示；文件写入使用临时文件或备份以降低数据损坏风险。
- **可维护性**：模块划分清晰，代码注释和 README 完备，便于学生理解与扩展。
